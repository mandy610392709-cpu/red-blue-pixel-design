# PPT模式

## 先看固定参考

先查看 `../assets/references/approved-ppt-opening.jpg`。它对应本人明确认可的前三页测试风格。`../assets/references/ppt-layouts.jpg`展示后续同风格扩展版式，不将其中每一页的排版都说成已单独获批。

包内 `../assets/references/approved-ppt-opening.pptx` 是保留幻灯片内容与布局的三页原生参考（公开版仅清理内部来源备注），有真实可编辑文字与色块，适合检查字体、位置和层级。它包含历史课程文字与备注：仅用于理解风格，新任务需按当次内容制作，不直接改标题后照搬其余课程事实。

使用当前环境支持的演示文稿工具或Skill，尊重用户指定的源文件、格式和交付位置。本Skill提供设计约束和版式依据，不替代目标工具的格式与导出流程。

## 内容组织

- 课程PPT文案以标题、关键句、短段落、必要表格为主。保留用户当次口述的清楚表达，不为套旧PPT而改成生硬口号。
- 文案阶段不预设固定页码，不写“上屏文案／讲解逐字稿”标签；制作阶段再根据讲解顺序和信息密度分页。用户指定页数或顺序时按指定执行。
- 先理解每段要讲什么，选择巨字、步骤、对照、截图或表格等版式；句子多就合理拆分，不把整篇讲稿缩进一页。
- 已有课件修改仅改授权范围；不恢复本人删除的内容。原课件有真实截图、互动、视频或游戏时保留其讲解作用，不用装饰图替代。

## 比例与尺度

默认课堂画布可按原参考16:9的1280×720逻辑尺寸设计，其他比例以用户要求为准。以下是原参考的坐标/字号范围，用于理解关系，不强制所有页面套同一坐标。

| 元素 | 原参考的逻辑尺度 |
|---|---|
| 左右内容边 | 约48px，内容宽约1184px |
| 一般页标题 | 顶部约28px起；字体约60–86px，长标题按语义分行 |
| 重点巨字 | 约110–280px，按词数和行数选择 |
| 正文 | 约32–44px；密集表格通常另行安排而非缩成脚注 |
| 次级说明 | 约22–30px，有需要且可读时使用 |
| 页脚 | 原参考约16–18px，接近底部682px；只是署名/页码，不放核心知识 |

这些为1280×720画布的设计单位，不等于PowerPoint的pt。用以英寸/pt计量的工具时按实际物理画布换算：例如1280px对应13.333英寸，则1px为0.75pt；避免把原px数字不加换算直接填进pt接口。

## 常用版式

| 版式 | 适用内容 | 关系与节奏 |
|---|---|---|
| 封面/章节巨字 | 课名、章节名、短观点 | 深蓝/粉色/冰蓝大色面，少量大字，小品牌头或主题副信息 |
| 横向色带 | 课程目录、几个层次、顺序关系 | 以整条色带分区，统一对齐；不做界面卡片堆叠 |
| 编号步骤 | 方法、制作步骤 | 粉色大编号＋深蓝/米白标题＋短说明，步骤间可用细线 |
| 左右对照 | 前后效果、两类方法 | 两栏或上下对照，标题与证据一一对应；不把比较内容做成同色正文一团 |
| 概念关系/流程 | Skill构成、工作流 | 原生文字、箭头和色面表达关系；图形数量服从真实关系 |
| 案例截图 | 工作台、历史对话、效果 | 截图占足够面积，标题简短，需要时加局部重点与来源说明 |
| 表格/课表 | 课程安排、分类、对比 | 原生表格或可编辑文字与线条，按信息层次配色，保留所需行列 |
| 互动/抽奖/收束 | 课堂节奏、关键动作 | 少量巨字搭配已有像素元素，与正文页形成变化 |

深蓝、米白、冰蓝和粉色按内容节奏切换，不要求机械轮换。连续页的模板、图文占比与重点位置要有变化，但整套字体、色板、页脚规则一致。

## 编辑与媒体

正文、标题、所需表格、数据和流程关系保留可编辑对象；真实截图与照片作为图片嵌入。不要将整页渲染图片冒充可编辑PPT。新插画通过当前可用图像工具处理，既有像素蝴蝶直接复用；原参考中的色块与像素语言按用户风格要求保留。

异机演示检查字体是否替换。制作工具支持且许可允许时可嵌入字体；否则随交付说明提供包内Noto字体或指定目标电脑可用的替代字体，并回看换字后的分页和文字边界。不能把本机字体渲染正常当成Windows已实测。

用户需要另一台电脑演示时，外部链接优先使用已验证可达的地址；本地网页/游戏必须随包携带完整依赖或另做便携版本，并实际检查入口。避免写死Mac的`/Users/...`绝对路径。依赖网络和浏览器/放映模式的条件要说清楚；能打开网页不等于PowerPoint已验证。

## 检查

查看实际页图：重点页是否有力量，正文页是否可读，图片/表格是否清楚，所有核心内容是否完整。检查文字盒溢出、孤字、意外遮挡、对齐和跨页重复。用最终目标格式回读检查页数、文字、编辑性、图片和媒体入口；只在实际使用相应软件验收过时才说“已在PowerPoint/Windows测试”。

交付指定位置的演示文稿或导出文件及必要预览。验证过程和来源明细放项目记录，不塞进面向观众的正文。
